# 🩺 Obesity Level Prediction Using Machine Learning

A Machine Learning project that predicts obesity levels based on physical and lifestyle attributes using multiple classification algorithms. The final model is deployed through an interactive Gradio web interface for real-time predictions.

## 📌 Project Overview

This project analyzes health and lifestyle data to classify individuals into one of seven obesity levels. Multiple machine learning models were trained and evaluated, with **Random Forest** selected as the final model based on its performance.

## 🚀 Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering (BMI)
- Multiple ML model comparison
- Random Forest classifier
- Interactive Gradio web application
- Real-time obesity level prediction

## 📂 Dataset

- **Dataset:** Obesity Levels Dataset
- **Source:** Kaggle
- **Records:** 2,111
- **Target Variable:** NObeyesdad (7 Obesity Categories)
